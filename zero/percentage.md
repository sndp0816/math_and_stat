\# Percentages

\### Basics • Fraction-to-% Conversion • Increase/Decrease • Successive % • Word Problems

\## 1. Percentage Basics



\*\*Percent\*\* means "per hundred." `x%` = `x/100`.



\### Converting Between Forms



| From | To | Method |

|---|---|---|

| Percentage → Fraction | Divide by 100 | `25% = 25/100 = 1/4` |

| Percentage → Decimal | Divide by 100 | `25% = 0.25` |

| Fraction → Percentage | Multiply by 100 | `1/4 = 1/4 × 100 = 25%` |

| Decimal → Percentage | Multiply by 100 | `0.25 = 25%` |



\*\*"Percentage of a quantity":\*\*

```

x% of y = (x/100) × y

```

\*\*Example:\*\* 20% of 250 = (20/100) × 250 = \*\*50\*\*



\*\*Finding what % one number is of another:\*\*

```

(Part / Whole) × 100

```

\*\*Example:\*\* 30 out of 120 = (30/120) × 100 = \*\*25%\*\*

\## 3. Percentage Increase / Decrease



\### Formulas



\*\*New value after increase:\*\*

```

New Value = Original × (1 + r/100)

```



\*\*New value after decrease:\*\*

```

New Value = Original × (1 − r/100)

```



\*\*Finding % increase or decrease:\*\*

```

% Change = \[(New Value − Original Value) / Original Value] × 100

```

(Positive result = increase, Negative result = decrease)



\*\*Example:\*\* A price rises from ₹200 to ₹250.

```

% increase = (250 − 200)/200 × 100 = 50/200 × 100 = 25%

```



\*\*Example:\*\* A price falls from ₹500 to ₹400.

```

% decrease = (500 − 400)/500 × 100 = 100/500 × 100 = 20%

```



\### Reverse Problems (finding the original value)



If a value \*\*increased by r%\*\* to become `N`:

```

Original = N × 100 / (100 + r)

```



If a value \*\*decreased by r%\*\* to become `N`:

```

Original = N × 100 / (100 − r)

```



\*\*Example:\*\* After a 20% increase, a number becomes 240. Find the original.

```

Original = 240 × 100/120 = 200

```

\## 4. Successive Percentage Change



When a quantity undergoes \*\*two or more percentage changes one after another\*\*, you can't simply add the percentages — use the successive change formula.



\### Formula (for two successive changes a% and b%)

```

Net % Change = a + b + (ab/100)

```

\- Use \*\*positive\*\* values for increase, \*\*negative\*\* for decrease.

\- Result: positive = net increase, negative = net decrease.



\*\*Example 1:\*\* A number is increased by 10%, then increased again by 20%.

```

Net change = 10 + 20 + (10×20)/100 = 30 + 2 = 32% increase

```



\*\*Example 2:\*\* Price increases by 20%, then decreases by 20%.

```

Net change = 20 + (−20) + (20×−20)/100 = 0 − 4 = −4% (net decrease of 4%)

```

⚠️ Notice: increase then equal decrease does \*\*not\*\* cancel out — there's always a net decrease when combining equal % increase and decrease.



\*\*Example 3 (three successive changes):\*\* Apply a% then to the result apply b%, then c%:

```

Final Value = Original × (1 ± a/100) × (1 ± b/100) × (1 ± c/100)

```

Apply the two-term formula repeatedly, or directly multiply the factors — multiplying factors is safer for 3+ changes.

\## 5. Population / Price Change Word Problems



These problems use \*\*compound-growth-style formulas\*\*, similar to compound interest.



\### a) Population/Price Increasing Every Year (constant r%)

```

Future Value = Present Value × (1 + r/100)ⁿ

```

where `n` = number of years/periods.



\*\*Example:\*\* A town's population is 50,000 and grows at 4% per year. Find the population after 3 years.

```

= 50,000 × (1.04)³

= 50,000 × 1.124864

≈ 56,243

```



\### b) Population/Price Decreasing Every Year (constant r%)

```

Future Value = Present Value × (1 − r/100)ⁿ

```



\*\*Example:\*\* A car worth ₹8,00,000 depreciates by 10% each year. Find its value after 2 years.

```

= 8,00,000 × (0.9)²

= 8,00,000 × 0.81

= ₹6,48,000

```



\### c) Finding Past Value (working backwards)

```

Past Value = Future Value / (1 + r/100)ⁿ    (if it was increasing)

Past Value = Future Value / (1 − r/100)ⁿ    (if it was decreasing)

```



\*\*Example:\*\* A population is 1,21,000 after growing 10% annually for 2 years. Find the original population.

```

Original = 1,21,000 / (1.1)² = 1,21,000 / 1.21 = 1,00,000

```



\### d) Alternating Increase and Decrease (common trick question)

Sometimes population/price increases one year and decreases the next.



\*\*Example:\*\* A population increases by 10% in year 1 and decreases by 10% in year 2. Starting population = 20,000.

```

After year 1 = 20,000 × 1.10 = 22,000

After year 2 = 22,000 × 0.90 = 19,800

```

Net effect ≈ −1% (matches the successive % formula: 10 + (−10) + (10×−10)/100 = −1%)

\## Quick Reference Summary



| Topic | Core Formula |

|---|---|

| x% of y | (x/100) × y |

| % one no. is of another | (Part/Whole) × 100 |

| % increase/decrease | (Change/Original) × 100 |

| Reverse (find original) | N × 100 / (100 ± r) |

| Successive % change | a + b + ab/100 |

| Growth over n years | P × (1 + r/100)ⁿ |

| Decay over n years | P × (1 − r/100)ⁿ |



\*\*Golden Tip:\*\* For any chain of percentage changes, converting each to a multiplying factor `(1 ± r/100)` and multiplying them together is the safest method — especially with 3+ successive changes.
